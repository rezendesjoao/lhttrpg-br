# Glossário — Log Horizon TRPG em português (Brasil)

Referência única para toda a tradução (interface, compêndios e regras). Quando um termo aparece aqui,
use **exatamente** esta forma, com a mesma grafia e as mesmas maiúsculas. Termos que não estão aqui:
traduza de forma natural, coerente com o resto.

## 1. Regras de estilo

- Português do Brasil, registro de livro de regras: claro, direto, voz ativa. Trate o jogador por
  **você** ("Você recebe +1D…"). Evite "tu" e mesóclise.
- Termos de jogo com inicial maiúscula como no inglês (Teste de Acerto, Processo Principal, Cena).
- **Nunca traduza nem altere**: fórmulas e variáveis (`@sr`, `@cr`, `@str.base`, `floor(@cr/2)`),
  notação de dados (`2D`, `3D+2`, `[[/gmr 2d6 + 5]]`), números, tokens `⟦a1⟧` / `⟦r1⟧`, tags HTML e
  atributos, entidades HTML (`&nbsp;`, `&laquo;`, `&times;`…).
- Mantenha a pontuação estrutural do original: colchetes `[ ]`, parênteses de nível `(NH2):`,
  aspas angulares `«nome de habilidade»`, `&lt;Nome Próprio&gt;`, `<hr>` separando regra e texto de ambientação.
- `«Nome»` cita outra habilidade/item: use o nome traduzido do mapa de nomes.
- Abreviações de dado: `D` continua `D` (`+1D`, `2D+4`). "Sq" vira **Qd** (`4Sq` → `4Qd`).
- O texto de ambientação (depois do `<hr>`) pode ser traduzido com liberdade literária; o texto de
  regra deve ser fiel e preciso.

## 5. Campos curtos das habilidades

**Momento (Timing)**: Major → Maior · Minor → Menor · Move → Movimento · Instant → Instantânea ·
Action → Ação · Interrupt → Interrupção · Setup → Abertura · Initiative → Iniciativa ·
Cleanup → Encerramento · Briefing → Briefing · Interlude → Interlúdio · Constant → Constante ·
Before Check → Antes do Teste · After Check → Após o Teste · Before Damage → Antes do Dano ·
After Damage → Após o Dano · Damage Roll → Rolagem de Dano · Pre-Play → Pré-Jogo ·
Rest Time → Descanso · Main Process → Processo Principal · Refer → Ver texto · Continuous → Contínuo.

**Alcance (Range)**: Close → **Corpo a corpo** · Weapon → Arma · `4Sq` → `4Qd` · Refer → Ver texto ·
Wide Area → Área Ampla.

**Alvo (Target)**: Single → Individual · Self → Pessoal · Area → Área · Wide → Amplo ·
Line → Linha · `2 Targets` → `2 Alvos` · (Select) → (Escolha) · (Indiscriminate) → (Indiscriminado) ·
(P) = Pick → **(E)** de Escolha · (A) = All → **(T)** de Todos.
Ex.: `Area (P)` → `Área (E)`; `Wide 20 (A)` → `Amplo 20 (T)`; `[Target: Single]` → `[Alvo: Individual]`.

**Custo (Cost)**: `Hate 2` → `Ódio 2` · `Fate 1` → `Destino 1` · `H(3) + F(1)` → `Ó(3) + D(1)`.

**Limite (Limit)**: `1/Scene` → `1/Cena` · `1/Scenario` → `1/Cenário` · `1/Round` → `1/Rodada` ·
`(SR)/Scene` → `(NH)/Cena`.

**Teste (Check type)**: `None` → Nenhum · `Opposed (Accuracy vs Evasion)` → `Oposto (Precisão vs Esquiva)` ·
`Opposed (8+2D vs Resistance)` → `Oposto (8+2D vs Resistência)` · `Basic (Perception vs Identification Difficulty)` →
`Básico (Percepção vs Dificuldade de Identificação)`.

## 10. Nomes próprios

Mantenha nomes próprios do cenário e termos japoneses consagrados: Akiba, Susukino, Minami, Yamato,
Elder Tale, Kannagi, Jingikan, Wuxia, Chindon'ya, Neirity, Vampnella, Rakshasa, Oobold. Traduza a parte
descritiva de nomes compostos ("Goblin Shaman" → "Xamã Goblin"; "Black Tanuki Tribe Harpooner" →
"Arpoador da Tribo Tanuki Negro").
